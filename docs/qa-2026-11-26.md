- **fix** (small): `vpn-conflict` failed when the controller did not answer and the config file had `device: utun` (number picked by macOS): it compared `utun` with `utun5`. Now no comparison is made for a bare `utun` (test added).
- `system-dns` prints `mihomo（）` when the config has no `dns.listen` (the check then expects `127.0.0.1`). Cosmetic.
- `twinnel helper install` plans `bootstrap` before `enable`. If the label had been disabled with `launchctl disable`, the bootstrap fails; `harden` already enables first. Low impact for a fresh install.
- No `twinnel version` command.
